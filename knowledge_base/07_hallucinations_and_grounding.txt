Hallucinations and Groundedness in LLMs

A hallucination is a statement generated by a language model that sounds fluent and confident but is factually wrong or entirely made up: an invented citation, a non-existent API parameter, a wrong date. Hallucinations are not occasional glitches; they follow from how the models work. An LLM is trained to predict the most plausible next token given the previous ones. Plausibility is judged against patterns in the training data, not against a source of truth, so when the model lacks knowledge it fills the gap with something that merely looks right. The fluent, assertive tone stays the same whether the content is correct or fabricated, which is what makes hallucinations dangerous.

Groundedness (also called faithfulness) is the property that every claim in an answer is supported by an explicitly provided source. A grounded answer may still be incomplete, but it does not contain statements the source material cannot back. In a RAG system the source material is the retrieved context, so groundedness can be checked: take each sentence of the answer and verify that some retrieved fragment supports it.

Retrieval reduces hallucinations for a simple reason: the model no longer needs to recall facts from its parameters, it needs to read them from the prompt, and reading is a task LLMs perform far more reliably. RAG does not eliminate the problem, though. The model can ignore the context and answer from memory, blend retrieved facts with invented details, or over-generalize from a partially relevant passage. Retrieval itself can fail and supply misleading fragments, and a model pressed to answer from bad context often obliges.

Practical mitigations stack on top of each other: strict prompting that forbids outside knowledge, mandatory citations of fragment numbers, low generation temperature, similarity thresholds that trigger an explicit "not found in the knowledge base" response, and automated evaluation that measures groundedness on a test set. A well-behaved RAG system prefers admitting ignorance to producing an unsupported answer.
